# Registro de Features y Planes Detallados

Este directorio `context/features/` está reservado para almacenar los planes detallados y features estructurados y documentados durante la evolución de **Transportaciones Vázquez Heredia**.

## Estructura Recomendada
- `FEAT-001-[nombre-feature].md`: Especificación técnica del feature o módulo.
- `checklist-[modulo].md`: Listas de control de aceptación y pruebas.

## Features en Proceso
- **FEAT-001 (Website Prototipo Persuasivo):** Maquetación responsiva en `protos/` con integración de catálogo de servicios, infraestructura en Altamira, galería fotográfica desde `/000/pics/` y formulario con enlace dinámico a WhatsApp/Email.
